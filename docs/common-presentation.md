## Purpose & Responsibilities

`src/common/presentation` provides **shared HTTP presentation utilities** for controllers:

- Swagger success-response decorators: `OkResponse`, `CreatedResponse`, `PaginatedResponse`.
- `PageOptionsDto` — validated query DTO for pagination with `toDatabaseQuery()` and `toResponseMeta()` helpers.
- *(Deprecated)* `RestResponse<T>` — the original response envelope class (replaced by direct DTO returns + `GlobalErrorFilter`).
- *(Deprecated)* `FormatRestResponseInterceptor` — the original response-wrapping interceptor.

---

## Architecture Overview

```
HTTP Request
      │ query params: pageNumber, pageSize
      ▼
Controller method (@Query() options: PageOptionsDto)
      │
      │ options.toDatabaseQuery() → { skip, take }
      │ service returns PagedResult<T>
      ▼
Swagger metadata generated by:
  @OkResponse(SomeDto)        → @ApiOkResponse with schema $ref
  @CreatedResponse(SomeDto)   → @ApiCreatedResponse with schema $ref
  @PaginatedResponse(SomeDto) → @ApiOkResponse with PagedResult + data[] schema
```

## Files

### `dtos/page-options.dto.ts`

#### `PageOptionsDto`

A validated query DTO for pagination. Controllers use this as `@Query()` parameter.

```typescript
class PageOptionsDto {
  pageNumber: number;   // 0-based. Default: 0. Min: 0.
  pageSize: number;     // Items per page. Default: 10. Min: 1, Max: 100.
}
```

**Validation decorators on each field:**
- `@IsNumber()`, `@IsOptional()` — field is optional, transforms to number.
- `@Type(() => Number)` + `@Transform(({ value }) => parseInt(value, 10))` — handles string query params from HTTP.
- `@Min(0)` on `pageNumber` with message `'Page number must be greater than or equal to 0'`.
- `@Min(1)` and `@Max(100)` on `pageSize` with descriptive messages.

**Methods:**

**`toDatabaseQuery()`**

Converts page options to Prisma-compatible `skip`/`take`:

```typescript
toDatabaseQuery(): { skip: number; take: number }
// skip = pageNumber * pageSize
// take = pageSize
```

**`toResponseMeta(totalItems: number)`**

Builds the `PageMeta` object for `PagedResult`:

```typescript
toResponseMeta(totalItems: number): {
  pageSize: number;
  pageNumber: number;
  totalItems: number;
  totalPages: number;       // Math.ceil(totalItems / pageSize)
  hasNextPage: boolean;     // pageNumber < totalPages - 1
  hasPreviousPage: boolean; // pageNumber > 0
}
```

### `rest/decorators/success-response.decorator.ts`

Three composable Swagger response decorators. They wrap `@ApiOkResponse` / `@ApiCreatedResponse` with correct `$ref` schemas and register the DTO model via `@ApiExtraModels`.

---

#### `OkResponse(dataDto)`

Generates `@ApiOkResponse` with `{ $ref: getSchemaPath(dataDto) }`.

```typescript
export const OkResponse = <DataDto extends Type<unknown>>(
  dataDto: DataDto | null,
) => MethodDecorator
```

- Pass `null` when the response body is empty: `@OkResponse(null)` → `{ properties: {} }`.
- Registers `dataDto` with `@ApiExtraModels` so Swagger picks up the schema.

---

#### `CreatedResponse(dataDto)`

Generates `@ApiCreatedResponse` (HTTP 201). Same signature as `OkResponse`.

```typescript
export const CreatedResponse = <DataDto extends Type<unknown>>(
  dataDto: DataDto | null,
) => MethodDecorator
```

---

#### `PaginatedResponse(dataDto)`

Generates `@ApiOkResponse` with a composite schema representing `PagedResult<DataDto>`:

```typescript
export const PaginatedResponse = <DataDto extends Type<unknown>>(
  dataDto: DataDto,
) => MethodDecorator
```

Schema structure in Swagger:
```
allOf:
  - $ref: PagedResult
  - properties:
      data:
        type: array
        items: { $ref: DataDto }
```

Both `PagedResult` and `dataDto` are registered via `@ApiExtraModels`.

### `rest/RestResponse.ts` — Deprecated

> **This class is deprecated. Do not use in new code.** Controllers should return DTOs directly. Errors are handled by `GlobalErrorFilter`.

`RestResponse<T>` is the legacy response envelope with `{ message, error?, data? }` shape.

```typescript
class RestResponse<T> {
  message: string;
  error?: RestError;
  data?: T;
}
```

**Static methods (all except `transformValidatorError` are deprecated):**

- `RestResponse.ok(data?, message?)` — **Deprecated.** Returns a success envelope.
- `RestResponse.error(name, errorMap, extra?)` — Looks up error by name in a legacy `ErrorMap` and returns an `HttpException`.
- `RestResponse.transformValidatorError(errors)` — Used by `main.ts` for `ValidationPipe.exceptionFactory`. Not deprecated — still in active use.
- `RestResponse.customError(message, httpCode, error)` — Custom HTTP error. Deprecated.

**`RestResponse.transformValidatorError`** is the one actively used piece of `RestResponse`. It converts `ValidationPipe` errors to an `HttpException` with the shape:

```typescript
{
  message: `validation.${property}.${constraint}`,
  error: {
    name: `${property}.${constraint}`,
    message: constraintMessage,
  }
}
```

Example: field `email` failing `isEmail` → `message = 'validation.email.isEmail'`.

### `rest/format-rest-response.interceptor.ts` — Deprecated

> **Deprecated. Do not use in new code.**

`FormatRestResponseInterceptor` wraps every controller return value in `RestResponse.ok(data)`. Superseded by controllers returning typed DTOs directly.

```typescript
@Injectable()
export class FormatRestResponseInterceptor<T>
  implements NestInterceptor<T, RestResponse<T>> {
  intercept(context, next): Observable<RestResponse<T>> {
    return next.handle().pipe(map((data) => RestResponse.ok(data)));
  }
}
```

## Current vs Deprecated APIs

| API | Status | Use instead |
|---|---|---|
| `OkResponse(dto)` | **Current** | Use for `GET` endpoints returning a single DTO |
| `CreatedResponse(dto)` | **Current** | Use for `POST` endpoints returning created resource |
| `PaginatedResponse(dto)` | **Current** | Use for `GET` list endpoints returning `PagedResult<T>` |
| `PageOptionsDto` | **Current** | Use as `@Query()` parameter for paginated lists |
| `RestResponse.ok()` | **Deprecated** | Return DTO directly from controller |
| `RestResponse.error()` | **Deprecated** | Throw `AppError` directly; caught by `GlobalErrorFilter` |
| `RestResponse.customError()` | **Deprecated** | Throw `AppError` directly |
| `RestResponse.transformValidatorError()` | **Active** (not deprecated) | Still used in `main.ts` `ValidationPipe` config |
| `FormatRestResponseInterceptor` | **Deprecated** | Remove `@UseInterceptors(FormatRestResponseInterceptor)` |

## Usage Patterns

### Paginated list endpoint

```typescript
import { Controller, Get, Query, UseGuards } from '@nestjs/common';
import { ApiTags } from '@nestjs/swagger';
import { AuthGuard, AuthContextUser } from 'src/common/auth';
import { PageOptionsDto, PaginatedResponse } from 'src/common/presentation';
import { PagedResult } from 'src/common/models';
import { UserDto } from './dtos/user.dto';

@ApiTags('users')
@Controller('users')
@UseGuards(AuthGuard)
export class UserController {

  @Get()
  @PaginatedResponse(UserDto)
  async findAll(
    @Query() options: PageOptionsDto,
  ): Promise<PagedResult<UserDto>> {
    return this.userService.findAll(options);
  }
}
```

### Single resource endpoints

```typescript
@Get(':id')
@OkResponse(UserDto)
async findOne(@Param('id') id: string): Promise<UserDto> {
  return this.userService.findById(id);
}

@Post()
@CreatedResponse(UserDto)
async create(@Body() dto: CreateUserDto): Promise<UserDto> {
  return this.userService.create(dto);
}

@Put(':id')
@OkResponse(null)
async update(@Param('id') id: string, @Body() dto: UpdateUserDto): Promise<void> {
  await this.userService.update(id, dto);
}
```

### Service using `PageOptionsDto`

```typescript
import { Injectable } from '@nestjs/common';
import { PageOptionsDto } from 'src/common/presentation';
import { PagedResult } from 'src/common/models';

@Injectable()
export class UserService {
  async findAll(options: PageOptionsDto): Promise<PagedResult<UserDto>> {
    const { skip, take } = options.toDatabaseQuery();

    const [users, totalItems] = await Promise.all([
      this.prismaService.client.user.findMany({
        skip,
        take,
        orderBy: { createdAt: 'desc' },
      }),
      this.prismaService.client.user.count(),
    ]);

    return new PagedResult(
      users.map(UserDto.fromDomain),
      options.toResponseMeta(totalItems),
    );
  }
}
```
